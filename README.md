# 📧 Система розсилки електронних листів

Клієнт-серверний застосунок для керування базою підписників та персоналізованої масової розсилки електронних листів. Проєкт реалізовано на базі Node.js з використанням бази даних MySQL та повністю запаковано в Docker для швидкого розгортання.

## 🚀 Основний функціонал

*   **Керування базою (CRUD):** Додавання нових адрес, редагування існуючих записів та їх видалення.
*   **Вибір отримувачів:** Можливість надсилати листи як усім підписникам одразу, так і лише обраним (за допомогою галочок).
*   **Шаблонізація повідомлень:** Вбудований набір категорованих шаблонів повідомлень (запрошення, системні сповіщення, фінанси тощо) з можливістю написати власний текст.
*   **Персоналізація:** Автоматичне підставлення імені, прізвища та по батькові кожного отримувача в текст листа.
*   **UI/UX:** Сучасний та адаптивний веб-інтерфейс на базі Bootstrap 5.
*   **Локалізація:** Повна підтримка кирилиці (UTF-8) в базі даних та на інтерфейсі.

## 🛠 Технологічний стек

*   **Бекенд:** Node.js, Express.js
*   **Фронтенд:** EJS (Embedded JavaScript templates), Bootstrap 5, HTML/JS
*   **База даних:** MySQL 8.0 (пакет `mysql2`)
*   **Відправка пошти:** `nodemailer` (інтеграція з Gmail SMTP)
*   **Інфраструктура:** Docker, Docker Compose
